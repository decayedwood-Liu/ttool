⚙️ 四、核心功能详解

4.1 做T匹配算法

  • 匹配优先级：T+0（当日）优先 > 组合记录数少优先 > 记录号大（时间晚）优先
  • 匹配模式：1对1 / 多对1 / 1对多 / 多对多（组合数量去重）
  • 匹配流程：未匹配记录 → 按日期分组 → 组合数量去重 → 优先匹配当日记录 → 匹配历史记录

4.2 盈亏计算逻辑

类型公式
浮动盈亏(当前价×持仓) - (成本价×持仓) - 预估卖出费用
当日盈亏昨日持仓盈亏 + 今日交易净现金流
做T盈亏卖出收入 - 买入成本 - 所有费用

4.3 预警与备注系统

策略类型说明
价格低于 / 高于股价触及设定价位时提醒
跌幅 / 涨幅超过涨跌幅超过设定百分比时提醒
盈利 / 亏损超过浮动盈亏率超过设定百分比时提醒
日期提醒在指定日期提醒
做T价差预警监控未匹配记录的价差机会

触发预警后，股票名称右侧会显示红色角标，显示未读数量。点击角标查看详情，可"全部已读"清除。

4.4 底仓仓位监控

为每只股票设定底仓数量和容差后，程序会在股票列表左侧显示仓位计：

  • 绿色：持仓在容差范围内，健康
  • 红色：持仓超过底仓 + 容差，超仓
  • 蓝色：持仓低于底仓 - 容差，不足

长按仓位计可查看详情：底仓、当前持仓、T仓、底仓占比、偏离度、总盈亏、做T盈亏、占总仓位、集中度评价、近30天仓位波动。

4.5 分时图与日K线

  • 分时图：记录软件运行期间的实时股价走势，支持长按设置参考线、做T区间、买卖标记等
  • 日K线：显示历史日K，支持 MACD / KDJ 副图切换
  • 分时图设置：长按分时图弹出设置面板，可调整参考线、做T区间（基于成本或昨收）、买卖标记显示

4.6 数据备份与同步

  • 本地备份：程序每日首次启动自动备份，保留最近3份
  • WebDAV 同步：支持坚果云等 WebDAV 网盘，可上传/下载股票数据和费率配置
⚠️ 重要： 移动版数据保存在应用私有目录，卸载软件会同时删除数据。建议定期使用"网盘同步"上传到云端备份。

5.2 导入交易数据

⚠️ 导入格式要求：
  • 文件格式：.xlsx 或 .xls（真正的 Excel 文件）
  • 必须包含以下列名（顺序不限）：日期、操作、价格、数量

💡 特别提示： 从同花顺等软件导出的交易记录，请先检查列名是否匹配。同花顺导出的 excel 文件并不是真正的 excel 格式，需要用 Excel 另存一下转换成真正的 Excel 格式后再导入。

❓ 六、常见问题与易错点

6.1 费率设置后不生效

❌ 常见错误： 修改费率后，已存在的股票没有变化。
✅ 正确做法： 费率设置仅对新添加的股票生效。已存在的股票需要删除后重新添加，或联系技术支持手动修改。

6.2 基础数据异常

❌ 现象： 搜索股票时找不到新上市的股票。
✅ 解决方法： 进入 设置 → 更新基础数据。

6.3 导入数据失败

❌ 常见错误： 导入 Excel 时报错"未找到有效的交易记录"。
✅ 正确做法：
  • 确保 Excel 是真正的 .xlsx 或 .xls 格式（同花顺导出的需先用 Excel 另存转换）
  • 确保列名完全匹配：日期、操作、价格、数量
  • "操作"列必须包含"买入"或"卖出"关键词
  • 日期格式建议为 YYYY-MM-DD

6.4 删除记录限制

❌ 常见错误： 想删除中间某条记录但无法操作。
✅ 正确做法： 为保持数据一致性，只能删除最后一条交易记录。如需删除中间记录，请删除该记录之后的所有记录，或重新建仓。

6.5 修改成本价后的影响

❌ 现象： 修改成本价后，部分交易记录前面显示 ★ 标记。
✅ 说明： 修改成本价会永久覆盖最后一条记录的逐次成本，并显示 ★ 标记。此操作不可逆，请谨慎使用。
💡 常见场景： 当你的股票发生分红配股后，需要手工修改成本价以反映真实的持仓成本。

6.6 清仓后继续交易

❌ 现象： 清仓后在同一天继续交易正常，但隔天再交易失败。
✅ 说明： 清仓后如需再次交易，程序会自动生成新的"段次"。
  • 当天清仓后继续交易 → 记录在同一段次（因为证券公司在盘后才进行清算，当天内清仓后重新购买不视为清仓）
  • 隔天交易 → 需要手动添加新的段次（同一股票再次添加）

6.7 数据备份提醒

⚠️ 强烈建议： 定期使用"网盘同步"上传数据到云端备份。移动版数据保存在应用私有目录，卸载软件会同时删除数据。

6.8 常见问题解答（FAQ）

Q1：授权异常怎么办？
检查系统时间和网络连接。如问题持续，联系 QQ 119073090。试用过期后如需要再次试用，请联系客服处理。
Q2：为什么无法获取股价？
检查网络连接和 Token 有效性。非交易时间（9:30-15:00 之外）无法获取实时行情。可尝试下拉刷新或点击刷新按钮。
Q3：做T匹配不正确？
检查交易时间和数量是否输入有误，可删除最后一条记录后重新添加，让匹配算法重新计算。
Q4：如何修改成本价？
长按股票 → "修改成本价"，输入新价格。注意：此操作会覆盖最后一条记录的逐次成本。
Q5：试用期后数据会丢失吗？
不会。升级正式版后恢复全部功能，所有数据保留。
Q6：清仓后可以增加交易记录吗？
当天清仓的可以在同一天继续交易（同段次）。隔天需要重新添加股票（新段次）。
Q7：如何批量导入交易记录？
长按股票 → "导入交易数据"，选择 Excel 文件。文件需包含：日期、操作（买入/卖出）、价格、数量 四列。
Q8：费率修改后为什么不生效？
费率设置仅对新添加的股票生效。已有股票需删除后重新添加，或手动修改（需技术支持）。
Q9：预警没有触发？
检查策略是否启用，检查触发模式设置（冷静期/单次/重复），检查是否满足触发条件。预警触发后股票名称右侧会出现红色角标。
Q10：如何删除中间的交易记录？
系统限制只能删除最后一条记录。如需删除中间记录，请删除该记录之后的所有记录，或重新建仓。
Q11：底仓仓位计是什么意思？
仓位计是股票列表左侧的竖条，显示当前持仓与底仓的偏离程度。绿色表示健康（在容差范围内），红色表示超仓，蓝色表示不足。长按仓位计可查看详细数据。
Q12：分时图为什么会有空白？
分时图记录的是软件运行期间的实时股价走势。软件未运行时不会有数据，因此可能出现空白。极值数据为软件采样数据，与真实数据可能存在差异。
